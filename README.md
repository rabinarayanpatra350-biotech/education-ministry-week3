# Education Ministry Internship — Project Work & Implementation

**Week 3 Task** | Education Ministry Internship, Coimbatore | Rabi Narayan Patra | 27 September 2026

A report applying the full project lifecycle to one real government project: **NIPUN Bharat**, the national foundational literacy and numeracy (FLN) mission, as implemented in Tamil Nadu through the **Ennum Ezhuthum Mission** — selected through a scored criteria matrix because learning outcomes (41.2 of 100 in PGI 2.0) is the weakest domain identified in the internship's own monitoring work (Week 2).

## The six objectives, each with verified numbers

| Objective | Key verified figures |
|----------|------------------------|
| 1. Project identification | Criteria matrix over 4 candidate projects; PM SHRI scored low (TN MoU unsigned, ~₹3,440 crore central share pending); FLN mission scored 24/25 |
| 2. Preliminary assessment | NAS 2021: Class 3 national average **62 (language) / 57 (mathematics)**; ASER 2024: **23.4%** of Class 3 govt-school children read a Class 2 text, **27.6%** do subtraction with borrowing; NIPUN Grade 3 Lakshyas (read with meaning ~60 wpm, numbers to 9,999, multiplication); risk register with 4 risks and mitigations |
| 3. Planning & resource allocation | **₹6,000+ crore** allocated via Samagra Shiksha PAB in 3 years (all India); TN: **₹152 crore** (2022-23) + **₹110 crore** (Classes 4-5); term-wise milestone table |
| 4. Field visits & consultations | Visit checklist (levelled workbooks, TLM kits, assessment use); stakeholder matrix; **65,000-teacher** Telegram feedback channel; parents via the Holistic Report Card (Oct 2025) |
| 5. Documentation | **25.08 lakh students** in **37,767 schools** (2025); **1.13 lakh teachers** trained; **98%** baseline assessment coverage; TN gains: **+15 pp** Class 3 arithmetic, **+10 pp** Class 5 reading (ASER 2022→2024); SLAS: TN above NAS 2021 national averages |
| 6. Presentation | Status summary + 5 evidence-linked recommendations |

## Why this project matters

Tamil Nadu's PGI 2.0 learning-outcomes score (41.2/100) is its weakest domain while infrastructure is near 100 — the FLN mission is the government's direct response. The Rajya Sabha Standing Committee's 363rd report has recommended extending the FLN mission to 2032, citing ASER evidence.
